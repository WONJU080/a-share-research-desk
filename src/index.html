说明

如何接入

  1. 前往你选择的 AI 服务商官网注册账号
  2. 在控制台创建 API Key
  3. 填写上方的 Base URL、Key、模型名
  4. 点击「测试连接」验证
  5. 保存后回来执行研究任务即可使用 AI 分析
配置以 JSON 形式保存在本机 userData 目录真实行情数据源将在后续版本接入
